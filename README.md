# kubernets_summary
# AI Notes App

AI-powered Notes Application using:

- FastAPI
- React
- MySQL
- Docker
- Kubernetes
- Groq AI

## Features

- Add Notes
- Update Notes
- Delete Notes
- AI Summarization
- Dockerized Backend
- Kubernetes Ready

## Run Backend

```bash
docker-compose up --build
```

## Frontend

```bash
npm install
npm start
```

## Tech Stack

- FastAPI
- React
- MySQL
- Docker
